## >> Sobre o Projeto
 
O **SmartDesk** é uma plataforma para gerenciamento de chamados (tickets) de suporte técnico com integração à IA, permitindo que usuários abram, acompanhem e gerenciem solicitações de suporte de forma simples e organizada. Este repositório contém o **frontend** da aplicação, responsável pela interface com a qual os usuários interagem para criar tickets, acompanhar seu andamento, visualizar comentários e gerenciar informações do sistema.
 
O frontend se comunica com o [Backend do SmartDesk](#) para realizar as operações de autenticação, criação e consulta de chamados, categorias, prioridades e demais dados da plataforma.
